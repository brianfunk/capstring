HTTP API

Free, no key, CORS enabled. Text up to 2,000 characters. Responses are JSON unless you add ?format=txt.

EndpointReturns
GET /api/stylesstyle names and categories
GET /api/:style/:text{ input, style, output }
GET /api/all/:textevery style
GET /api/chain/:styles/:textstyles applied in order, e.g. upper+reverse
POST /api/batchbody { "style": "kebab", "texts": ["a", "b"] }
GET /api/badge/:style/:textshields-style SVG badge for your README (?label= to override)
GET /api/lorem/:countlorem ipsum words, 1 to 1000, optional ?style=
GET /api/spell/:textspell-corrected text with a list of corrections, optional ?style= (max 500 chars, 50 corrections)
 
curl https://capstring.netlify.app/api/title/hello%20world
curl "https://capstring.netlify.app/api/all/hello%20world?format=txt"
curl -X POST https://capstring.netlify.app/api/batch \
  -H "Content-Type: application/json" \
  -d '{"style":"slug","texts":["Crème Brûlée","Hello World"]}'
curl "https://capstring.netlify.app/api/spell/helo%20wrld?style=title"
curl -o badge.svg https://capstring.netlify.app/api/badge/sponge/hello%20world

Errors look like { "error": { "code": "unknown_style", "message": "..." } }. Use ?text= instead of the path when your text contains slashes.
